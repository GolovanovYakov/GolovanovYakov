# 📈 Анализ эффективности маркетинговой промо-акции и прогнозирование выручки

### 📊 Описание проекта
Бизнес провел масштабную рекламную промо-акцию длительностью 92 дня. Главный вопрос исследования: **принесла ли акция реальный дополнительный доход (Revenue) или компания сработала в ноль/убыток** с учетом затрат и естественного тренда?

Для ответа на этот вопрос в проекте реализован продвинутый подход: на основе исторических данных до начала акции построена модель прогнозирования временных рядов. Реальные показатели выручки во время промо-периода сравнивались с верхней границей прогнозных значений (базовым сценарием «если бы акции не было»).

### 🛠️ Технологический стек
* **Язык:** Python
* **Библиотеки:** `Pandas`, `NumPy`, `Plotly.Express` (интерактивная визуализация)
* **Анализ временных рядов и ML:** `Prophet` (от Meta), критерий Дики-Фуллера (`statsmodels`)

---

### 🗺️ Ход исследования и методология

1. **Исследовательский анализ (EDA) и предобработка:**
   * Загрузка данных, явное приведение типов к `DateTime`.
   * Анализ распределения выручки, поиск и удаление аномальных выбросов с помощью **метода квартилей (IQR)**.
   * Визуализация первоначального и очищенного рядов выручки на одном графике.

2. **Анализ временного ряда на стационарность:**
   * Проверка ряда на стационарность с помощью **теста Дики-Фуллера (ADF-test)**.
   * Определение характеристик ряда (наличие тренда, сезонности) для обоснованного выбора модели прогнозирования.

3. **Моделирование и Прогнозирование (Prophet):**
   * Разделение исторических данных на обучающую и тестовую выборки (Train/Test split) для валидации модели.
   * Оценка качества прогноза модели `Prophet` на тестовых данных.
   * Построение финального прогноза выручки на 92 дня вперед (период проведения промо-акции).

4. **Бизнес-анализ результатов акции:**
   * Расчет среднемесячной базовой выручки компании.
   * Сравнение фактической накопленной выручки за период акции с верхней границей прогнозных значений.
